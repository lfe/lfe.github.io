## Semantic tokens

A semantic token names a job, while its expression points to a paint. The same role may resolve differently by mode. This table is projected from the current CSS declarations and checked against the source palette, so it describes the implementation as it stands.

The role purpose and consumer notes are maintained separately from the values. Code and artwork exceptions retain their own ownership; the legacy code-tab variables do not paint the current widget tabs.
