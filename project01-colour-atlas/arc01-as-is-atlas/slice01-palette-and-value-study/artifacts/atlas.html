Lightness is the measure.

Here, L means Oklab/OKLCH lightness. It is not relative luminance, a contrast ratio or HSV value. Neutral counterparts hold L while removing chroma; they are study samples, not replacement palette tokens.

Read the calculation method +

For authored OKLCH, L is read directly (percentage divided by 100). For hex values, each sRGB channel is decoded to linear light: u / 12.92 at u ≤ 0.04045, otherwise ((u + 0.055) / 1.055)^2.4. Linear RGB is transformed to LMS, cube-rooted, then transformed to Oklab L.

The L calculation uses the Oklab matrices: LMS rows [0.4122214708, 0.5363325363, 0.0514459929], [0.2119034982, 0.6806995451, 0.1073969566], [0.0883024619, 0.2817188376, 0.6299787005]; L coefficients [0.2104542553, 0.7936177850, −0.0040720468].

For neutral counterparts, linear neutral intensity is L³, then encoded to sRGB and rounded to the nearest 8-bit channel. Neutral swatches are therefore approximate; calculations and sort keys retain floating-point precision. The black/white witnesses return 0 and approximately 0.9999999935. The same numerical L does not guarantee identical perceived brightness in every surround.

Alpha is read independently. #addb67ff remains explicitly opaque; #EF535090 remains translucent. No composited-lightness number is assigned to the translucent paint. Unsupported measurements would be labelled unavailable, never zero.

05 / SOURCE NOTES

Keep the evidence attached.

This atlas describes the selected source population. It does not propose new colours, certify accessibility or establish which tokens are used on every route.

What is included

  • src/css/site.css: 11 gold and 41 foundation declarations in root scopes.
  • src/css/highlight.css: 40 explicit paint declarations, expanded to 43 selector/property records.
  • Source baseline: 036e231b09c48966da26d2227bccb4fa3b295df9.
  • Source bindings read from tailwind/site.css:1–115; stylesheet links and theme context read from src/_includes/css.liquid and home/page layouts.

What remains outside the frame

Common styles, search overrides, inline paints, images and resolved component state pairs belong to later work. Legacy Sass and src/lfe.css are not this baseline.

The neutral surround and specimen-book composition are atlas presentation choices. Original paints and alpha have not been corrected or substituted.

First attempt for Duncan and Sofie’s review. Browser inspection, visual judgment and independent acceptance remain pending.
